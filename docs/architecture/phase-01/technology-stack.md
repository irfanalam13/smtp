## Security and licensing notes

Rust/Go/Next.js and the existing Apache-2.0 workspace license do not by themselves establish compatibility for every transitive dependency. Phase 05 must produce an SBOM, license report, vulnerability policy, and release artifact provenance. External SMTP/TLS/DNS libraries require license and maintenance review before production adoption.

## Migration strategy

Keep application interfaces independent of PostgreSQL queue internals, object-storage SDKs, DNS resolver implementations, and identity-provider APIs. The first replacement seams are the queue store, content store, resolver, identity verifier, event publisher, and telemetry exporter. A migration is not justified by fashion; it requires benchmark, incident, cost, or compliance evidence.
